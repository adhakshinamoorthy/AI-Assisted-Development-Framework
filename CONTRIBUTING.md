# Contributing

Open an issue for substantial changes. Keep pull requests focused, explain the problem and AI-specific risk, add tests and docs, and run `dotnet build Aide.slnx -c Release` plus `dotnet test Aide.slnx -c Release`. Do not submit generated code you have not understood and reviewed. Never include secrets, proprietary prompts, personal data, or model weights without redistribution rights.

Commits should be small and descriptive. Security vulnerabilities should be reported privately through the repository's security advisory channel, not a public issue.
