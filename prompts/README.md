Prompts are versioned engineering assets. Each template asks for context, constraints, evidence, output format, and verification. Replace every `{{placeholder}}`; never paste secrets or regulated data.

| Documentation | [documentation.md](documentation.md) | 30–60 minutes |

\*Illustrative only. Validate generated work; savings vary by context, model, hardware, and review depth.
